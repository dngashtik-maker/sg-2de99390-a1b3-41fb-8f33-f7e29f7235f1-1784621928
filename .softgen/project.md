# Membership Directory

## Vision
A membership directory application for viewing and searching organization members. Target users: administrators and members who need quick access to member information in a data-centric, scannable format.

## Design
Industrial-utilitarian aesthetic with monospace typography and data-grid layout.

Colors (HSL):
- `--background: 210 20% 98%` (cool-tinted near-white)
- `--foreground: 215 25% 20%` (deep charcoal)
- `--primary: 215 20% 35%` (steel blue)
- `--accent: 38 92% 50%` (amber)
- `--muted: 210 15% 92%` (light steel)
- `--card: 0 0% 100%` (pure white)
- `--border: 215 15% 85%` (steel grey)

Typography:
- Headings: IBM Plex Mono (600, 700)
- Body: Space Mono (400, 700)
- Data: tabular-nums applied throughout

Style: Tight grid, generous line-height, monospace-driven, data-table aesthetic, minimal decoration, functional color usage.

## Features
- Member directory with grid view
- Individual member profile pages
- Search and filter functionality
- Member cards with photo, name, role, contact
